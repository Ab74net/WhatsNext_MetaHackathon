# What Next web app

Next.js, React and TypeScript frontend for What Next, with the Wren assistant, photo-based
inventory workflow, Memory Web, Aid Autopilot and Recovery Toolkit.

See the [project README](../../README.md) for setup, the judge walkthrough, model
configuration and privacy details. Run the setup and development commands from the
repository root; the frontend forwards `/api/*` requests to the FastAPI backend.
